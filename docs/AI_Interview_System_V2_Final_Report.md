# AI 모의 면접 시스템 V2 최종 보고서

## 1. System Architecture 요약 (데이터 흐름 중심)

AI 모의 면접 시스템 V2는 React(Vite) 프론트엔드와 FastAPI 백엔드를 기반으로 구현되었으며, 다양한 AI 서비스 모듈이 하나로 묶여 실시간 면접 시뮬레이션을 제공합니다.

### 🌐 프론트엔드 (React + Tailwind + Zustand/Context)
- **UI 및 상태 관리**: `react-router-dom`으로 라우팅을 구성하고, 모듈화된 React 컴포넌트(`MyPage`, `AdminDashboard`, `ChatRoom`, `Report`)로 사용자 경험을 분리합니다.
- **오디오 & 비전 데이터**: 브라우저의 `navigator.mediaDevices.getUserMedia`를 통해 실시간 웹캠 및 마이크 스트림을 수집합니다.
    - **Vision (웹캠)**: 면접 중 주기적으로(초 단위) 백엔드로 JPEG 이미지를 Base64 변환하여 POST 전송합니다.
    - **Voice (STT/TTS)**: 사용자의 음성은 Web Speech API (또는 위스퍼 등)로 텍스트화되어 백엔드로 넘어가며, AI의 답변은 백엔드에서 생성된 오디오 파일(TTS) URL로 응답받아 동적으로 재생됩니다.

### ⚙️ 백엔드 (FastAPI) & 데이터베이스 (PostgreSQL)
- **API 및 라우팅**: `routers/interview.py`, `routers/admin.py`, `routers/auth.py` 공간으로 나뉘어 프론트엔드의 REST API 요청을 처리합니다.
- **RAG & 임베딩 파이프라인**: 
    - 직무 공고(Job Posting) 기반 질문과 `QuestionBank`의 임베딩(`pgvector` 유사 로직) 데이터를 비교 연산합니다.
    - LangChain을 통해 문맥(Context)을 조합하여, 최근 지원자의 이력서, 직무 요건 파악 후 꼬리 질문을 생성합니다.
- **DB (SQLAlchemy)**: 사용자 정보(`users`), 공고(`job_postings`), 면접 이력 및 채팅 로그(`transcripts`), 최종 리포트(`evaluation_reports`) 등을 관계형 DB와 JSON(B) 포맷을 섞어 영구 저장합니다.

### 🧠 AI 모듈 Orchestration
- **Face/Emotion (Vision)**: 프론트엔드가 보낸 Base64 프레임에서 얼굴을 감지해 긍정/중립/부정 등의 감정을 실시간으로 분석(`vision_data`), Timeline 배열로 유지.
- **LLM 본체**: OpenAI/Claude 계열 LLM을 사용하여, 1) 인터뷰 질문 채점 로직(0-100), 2) 면접 태도 통합, 3) 후속 질문 자동 생성, 4) 최종 평가 리포트 텍스트 렌더링 역할을 모두 수행합니다.

## 2. 세부 기능 명세서

### 👤 일반 사용자 (지원자)
1. **마이페이지 (`MyPage.jsx`)**
    - **내 정보 및 이력서 관리**: 텍스트 입력 또는 PDF 파일 업로드 시 LLM을 사용해 자동 텍스트 추출/병합.
    - **면접 결과 이력 탭**: 과거 면접 점수(총점, 직무, 의사소통, 면접태도) 내림차순 정렬 및 카테고리별 요약 제공.
    - **표시된 공고 리스트 (`Job Board`)**: 직무 설명/우대조건 "상세보기 모달", 바로 지원하기 흐름 연동 (마감일, 경력 여부 노출).

2. **면접 대기실 (Green Room)**
    - 모의 면접 진입 직전, 오디오/웹캠 정상 작동 유무를 브라우저 단에서 점검하여 UI 상에 라이브 미러링 형태로 테스트 수행.

3. **실시간 면접 방 (`ChatRoom.jsx`)**
    - **면접 진행 타이머**: "AI 면접관" 화면 옆 현재 누적 인터뷰 시간 계산.
    - **STT 기반 텍스트 소통**: 마이크를 이용한 음성 인식 또는 타이핑으로 답변 전달 가능. 자동 턴 종료 시 다음 질문 대기.
    - **실시간 TTS 플레잉**: 브라우저 Audio Playbar 우회를 위해 최초 "면접 시작" 상호작용 후, AI의 모든 대답을 오디오 파동 애니메이션과 함께 자연스레 청취.
    - **Vision 백그라운드 후킹**: 사용자의 면접 표정(행복, 중립, 당황 등) 타임라인 추적.
    - **실시간 평가 바**: 턴이 끝날 때마다 답변에 대한 직무 모범 답안 평가, 피드백 점수 즉시 노출.

4. **면접 결과 피드백 (`Report.jsx`)**
    - **AI 종합 평가 & 역량 레이더 차트**: 종합, 직무역량, 의사소통, 문제해결, 면접태도 간의 방사형 그래프 가시화.
    - **비언어 감정 분석 타임라인**: 면접 진행 동안의 표정 변화 추이를(Recharts 활용) 선 그래프로 표현. (긍정/중립/부정).
    - **세부 장단점/통합 대화록**: 텍스트 전문, PDF 제출 이력, JD Fitting 매칭 등 텍스트 요약 지원.

### 👑 관리자 (Admin)
1. **어드민 대시보드 (`AdminDashboard.jsx`)**
    - 직무 공고 현황 조회, 필터링. 새로운 직무 생성 시 마감일 및 직무 설명 등 구조화 추가 (Sticky 스크롤 폼).

2. **통계 분석 (Admin Analytics)**
    - **공고별 지원 현황 바 차트**: 특정 공고에 모인 Applicant 누적 면접 건수 시각화.
    - **출제된 질문 카테고리 (Question Categories)**: AI가 각 세션에 던진 RAG/DB 상 질문들의 빈도수 분포 Bar 통계 (CS, 개발, 태도 등).
    - **지원자 평균 역량 카드**: 모든 지원자가 획득한 각 파라미터(커뮤니케이션, 직무 등) 평균 점수 ProgressBar.

3. **리더보드 & 지원자 리력 (Leaderboard 탭)**
    - 드롭다운으로 특정 직무에 대한 최상위권 랭크 지원자 열람 체계.
    - 지원자의 'PDF 이력서 다운로드' 및 '제출된 모의 면접 결과 전문' 상세 접근 가능 구조.
